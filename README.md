# Opti & Co App

**Entretenir, comprendre et réparer son PC, simplement.**

Application Windows par Opti & Co pour nettoyer, surveiller et dépanner votre PC, avec des explications claires même si vous n'y connaissez rien.

> Aucun « boost FPS » magique : uniquement des réglages réels et vérifiables.
> L'application ne fait pas d'optimisation poussée de Windows. Pour ça, il existe le service **Optimisation complète** d'Opti & Co.

## Télécharger

👉 **[Télécharger la dernière version](https://github.com/Strelox59/opti-co-releases/releases/latest)**

Dans la page qui s'ouvre, choisissez le fichier `OptiCoApp_..._x64-setup.exe` dans la rubrique **Assets**.

- Compatible avec Windows 10 et 11, en 64 bits.
- L'application demande les droits administrateur au lancement (nécessaires pour le nettoyage et les diagnostics).

### Windows affiche « Windows a protégé votre ordinateur » ?

C'est normal pour une nouvelle application. Cliquez sur **Informations complémentaires**, puis sur **Exécuter quand même**.
